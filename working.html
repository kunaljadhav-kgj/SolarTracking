Working Principle

The system uses Light Dependent Resistors (LDRs) to compare light intensity from different directions. An LDR's resistance changes with the amount of light falling on it: brighter light generally lowers its resistance.

Working Process

  1. Detect sunlight: LDR sensors placed on different sides of the panel sense the incoming light.
  2. Generate signals: Each LDR and a fixed resistor form a voltage divider that produces a voltage reading.
  3. Process readings: A controller such as an Arduino reads and compares the sensor values.
  4. Compare direction: If one side receives more light, the controller determines which way the panel should turn.
  5. Move the panel: The controller sends a signal to the servo motor to adjust the panel toward the brighter side.
  6. Repeat: The readings are checked continuously so the panel can respond as the sun moves.

LDR Sensor Logic

  • Left LDR receives more light → move toward the left.
  • Right LDR receives more light → move toward the right.
  • Both sensors receive similar light → stop the motor.
  • Low-light conditions → keep the motor stationary.
Note: Actual motor direction depends on the sensor arrangement and wiring. A small tolerance can prevent unnecessary movement when readings are nearly equal.
