Module 01

Introduction to Solar Tracking System

What is a Solar Tracker?

A Solar Tracking System is an automated electromechanical device that orients a solar photovoltaic (PV) panel directly toward the Sun throughout the day. Because the Sun's position in the sky changes continuously from East to West (and seasonally from North to South), fixed solar panels only receive peak sunlight for a few hours around noon.

By keeping the solar panel perpendicular (at a 90° angle of incidence) to the sun's rays, a solar tracker minimizes reflection loss and maximizes energy absorption, increasing electricity generation by 25% to 40% compared to stationary panels.

+35%
Average Power Gain

Cosine Law of Illumination: Maximum power is generated when the angle between sunlight and panel surface normal is 0° (cos 0° = 1).

Arduino C++ Control Code 

#include <Servo.h>

Servo solarServo;
int ldrEastPin = A0;
int ldrWestPin = A1;
int servoPos = 90;
int tolerance = 15;

void setup() {
  solarServo.attach(9);
  solarServo.write(servoPos);
  delay(500);
}

void loop() {
  int eastVal = analogRead(ldrEastPin);
  int westVal = analogRead(ldrWestPin);
  if (abs(eastVal - westVal) > tolerance) {
    if (eastVal > westVal && servoPos > 10) servoPos--;
    else if (westVal > eastVal && servoPos < 170) servoPos++;
    solarServo.write(servoPos);
  }
  delay(50);
}

Advantages, Limitations & Future Scope

Key Advantages

• 25%–40% Higher Energy Yield: Keeps panel perpendicular to solar radiation all day.

• Optimal Space Efficiency: Generates maximum kWh per square meter of installation area.

• Low-Power Automation: Servo actuator draws minimal energy compared to gained output.

Future Scope

• IoT Live Telemetry: ESP32 cloud dashboard for mobile voltage/current tracking.

• Dual-Axis Upgrade: Adding elevation tracking for seasonal North-South sun tilt.

• Automated Wiper Cleaning: Removes morning dust automatically to preserve efficiency.
